WEIGHT GAIN TRACKER — PANDUAN SINGKAT

Isi folder:
- index.html: dashboard aplikasi
- manifest.webmanifest: metadata aplikasi web
- sw.js: dukungan offline setelah pertama kali dibuka
- icon.svg: ikon aplikasi

CARA MEMAKAI DI ANDROID
1. Upload seluruh isi folder ini ke hosting HTTPS (contoh: GitHub Pages).
2. Buka alamat website hasil hosting melalui Chrome Android.
3. Buka menu ⋮ Chrome > Tambahkan ke layar utama / Install app.
4. Ikon Weight Gain akan muncul di layar utama.

DATA & PRIVASI
- Catatan disimpan secara lokal di browser/perangkat melalui localStorage.
- Data tidak otomatis tersinkron ke perangkat lain.
- Gunakan menu Statistik > Ekspor data untuk membuat cadangan JSON.
- Jika cache/browser dihapus atau memakai browser/perangkat berbeda, data lokal dapat hilang. Ekspor cadangan secara berkala.

CATATAN
Target 2.550 kkal dan 90–100 g protein adalah estimasi awal, bukan resep medis.
Sesuaikan dengan tren berat badan, nafsu makan, aktivitas, dan kondisi kesehatan.
